# Release provenance

This public package was curated from local paper-2 research code and frozen experiment snapshots on 2026-10-10. It contains a selected, import-complete v30–v36 script chain rather than every historical diagnostic script. Primary checkpoints came from the `sparse-detail-v32-lowpass` three-seed final training endpoints. Ablation checkpoints came from the four variant, three-seed stage-2 final endpoints. Source raster data and intermediate predictions were deliberately excluded.

The code was originally organized as an internal research framework. The corresponding author confirmed authority to publish this framework. Original contributor attribution in `pyproject.toml` is retained. No open-source reuse license is asserted.

The R2C5 HiRISE input limitation described in `README.md` was already present in the local experiment record. This repository does not relabel digitized images as native prediction arrays.
